# キャラクター・装備仕様_v1（MVPたたき台）

本書は **ゴーレム（プレイヤーキャラクター）** のステータスと、装備（武器/防具/アクセ）および武器スキルの **MVP向け確定案** をまとめたものです。  
数値は最初のバランス用「たたき台」であり、後から調整可能です（データ構造は維持）。

---

## 0. 共通ルール

### 0.1 単位
- **Move**：タイル/秒（タイル＝グリッド1マス）
- **Sensor R**：タイル半径（円形）
- **Energy Regen**：/秒
- **時間（回避CT / スキルCD / CastTime）**：秒

### 0.2 ダメージ計算（MVP・超シンプル）
- **攻撃パワー** = `floor(ATK × 係数)`
- **最終ダメージ** = `max(1, 攻撃パワー − 相手DEF)`
- 通常攻撃もスキルもこの式で統一（係数だけが変わる）

### 0.3 行動状態（Running統一）
- 通常攻撃・スキル・回避・解除は「開始 → Running（時間経過）→ Success」で統一
- 条件不足（射程外/エネルギー不足/CD中など）は **Failure即時**

## 3. 装備枠（MVP確定）
- **武器×1**
- **防具×1**
- **アクセ×2**
  - 同名アクセは基本2つ装備OK（効果は加算）
  - ただし **解除ツールのみ重複不可（1個まで）**

## 4. レアリティ（MVP確定）
- **Common / Rare / Epic** の3段階
- レアリティで増えるのは **数値部分のみ**
  - モーション/射程/回避距離/無敵/固定硬直などは変えない
- 各装備の **C/R/E値** を下に明記

# 9. 動作確認用：サンプルビルド（計算例）
