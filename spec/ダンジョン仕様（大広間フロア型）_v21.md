本ドキュメントは、ダンジョンの「大広間フロア型」設計を前提に、分岐ルート・報酬選択・戦利品/通貨/撤退清算まで含めて **最新の確定仕様** をまとめたもの。

- **v21変更点**：9.5.2 に「罠ごとの `footprint_tiles / static_tiles`」テーブル（概算タイル数）を追加
- **v20変更点**：9.5.2 に「★別の密度/罠個数」テーブルを追加（生成が安定するよう明文化）
- **v19変更点**：9章「罠」を詳細化（TrapTier/罠セット/共通ルール/配置制約/スケーリング）
- **v17変更点**：敵キャラ関連の詳細（敵種/Threat Budget/エリート・ボスの強化/攻撃パターン）は別紙 **「敵キャラ仕様_v2.md」** に分離。

## 1. 目的・コンセプト

- **自動操縦（AI操作）前提で“詰まらない”**
  - 迷路・複雑なスイッチ・鍵開け等は基本採用しない
  - 罠・ギミックは「検知 → 回避」が成立する見た目/挙動に限定する
- **ローグライトの意思決定を「UI選択」と「大広間内の行動」で成立させる**
  - 次フロア分岐をユーザーがUIで選ぶ
  - 宝箱（リスク/リターン）を開けるタイミングをAIが判断する
  - フロア終了ごとに報酬選択を行う
  - 安全ポイント撤退で「成果確定して帰る」判断を持てる

## 2. ランの地図構造（分岐）

### 2.1 基本
- ランは階層（Depth）で進行する
- **各階層の終了時に「次フロア候補」を提示し、ユーザーが選択**する
- 選択結果に応じて、次フロアを生成して進行する

### 2.2 次フロア候補の提示ルール（MVP推奨）
- 提示数：**2択**（将来3択へ拡張可能）
- 候補は「フロアタイプ」＋「危険度/報酬傾向」を持つ

### 2.3 ボス周期との整合
- ボスは一定間隔で出現する（例：`BOSS_INTERVAL=5`）
- ボス直前は **インターミッション（回復＋ショップ）** 固定
- ボス階は **ボスフロア** 固定
- 分岐は上記以外の通常階で発生する


### 2.4 最終階（ランの終点）
- ダンジョンの最終階は **20階** とする
- **20階にラスボス**（最終ボス）を配置し、撃破でランをクリア扱いとして終了する
- `BOSS_INTERVAL=5` の場合、ボス階は **5/10/15/20**（計4回）となり、20階が自然に締まる
- ボス直前（4/9/14/19階）は **インターミッション（回復＋ショップ）** 固定

---


### 2.5 章立て（バイオーム / Act）
- ダンジョンは **5階ごとにバイオーム（Act）を切り替える**（20階版＝4Act）。
- Act切り替えは「ルールは共通のまま、見た目・出現テーブル・報酬傾向の“セット差し替え”」で表現する。

#### 2.5.1 Act一覧（20階版：初期値）
| Act | 範囲 | 節目 | テーマ（仮） | 主な追加/変化（例） |
|---:|---|---|---|---|
| Act1 | 1–5 | 5F：ボス | 遺跡入口 | 近接/遠距離中心。エリート無し。罠/トラップ宝箱は軽め（TrapTier=1）。 |
| Act2 | 6–10 | 10F：ボス | 地下水路 | **突進**解禁。エリート低確率解禁。罠の種類を追加（TrapTier=2）。 |
| Act3 | 11–15 | 15F：ボス | 工廠区画 | **硬い**＋**範囲（or 支援）**解禁。エリート中確率。罠/トラップ宝箱が強め（TrapTier=3）。 |
| Act4 | 16–20 | 20F：ラスボス | 中枢 | 全要素フル。エリート高確率。TrapTier最大（=4）。ラスボスのクロスレーザー等。 |

> テーマ名は仮。Actの区切り（5階ごと）と「差分の入れ方」は固定し、見た目や名称は後から差し替え可能。

#### 2.5.2 Actで切り替える要素（管理単位）
- **見た目**：床/壁/背景小物、BGM/SE、危険床・射線の見た目（ただし判別性は維持）
- **出現テーブル**：敵の出現重み、罠種テーブル、宝箱（通常/トラップ）比率、エリート出現重み
- **報酬傾向（任意）**：回路チップ寄り / 装備寄り / 遺物寄り等（分岐候補タグと連動させられる）
- **ボス**：各Act末尾にボス（5 / 10 / 15 / 20）を配置

#### 2.5.3 投入計画（初期値）
- **Act1（1–5）**：近接/遠距離のみ（硬い/突進/範囲（支援）は出さない）。エリート無し。
- **Act2（6–10）**：突進を解禁。エリートを低確率で解禁（16章の「エリート★3〜5のみ」と整合）。
- **Act3（11–15）**：硬い＋範囲（or 支援）を解禁。混成の濃さを上げる。
- **Act4（16–20）**：全要素フル。エリート頻度を上げ、罠/トラップ宝箱のTierも最大にする（8.2.5 と一致）。


## 3. 分岐で出るフロアタイプ（セット）

> ※ボスフロア/インターミッションは固定枠のため、分岐候補には含めない。

### 3.1 コアセット（推奨：まずはこれで運用）
1) 戦闘（通常）  
2) 宝箱（宝箱多め）  
3) 罠（罠多め）  
4) エリート（強敵＋報酬強化）

### 3.2 各フロアタイプの定義（生成と報酬の“違い”）
- **戦闘（通常）**
  - 生成：敵=標準、宝箱=少、罠=少
  - クリア：敵全滅で階段出現
  - クリア報酬：報酬選択（3候補→1つ）
- **宝箱**
  - 生成：宝箱=多、敵=少〜標準、罠=標準（宝箱周辺に寄せる）
  - クリア：敵全滅で階段出現
  - クリア報酬：報酬選択（3候補→1つ）
  - 特記事項：宝箱は「通常宝箱／トラップ宝箱」の2種。トラップ宝箱は解除に成功すると安全に開封でき、失敗または強制開封でペナルティ（ダメージ／デバフ／毒）を受ける。トラップ宝箱は通常より**報酬レア率ボーナス**が付く。
- **罠**
  - 生成：罠=多、敵=少〜標準、宝箱=少
  - クリア：敵全滅で階段出現
  - クリア報酬：報酬選択（3候補→1つ）
- **エリート**
  - 生成：エリート敵=1体（or 1集団）＋取り巻き少、罠=少〜標準、宝箱=少
  - クリア：敵全滅で階段出現
  - クリア報酬：**報酬選択を強化（4候補→1つ）**（レア率アップ／高レア保証などは★に応じて追加可能）

### 3.3 分岐カードUI（表示項目の例）
- フロアタイプ名（アイコン）
- 危険度（★1〜5）
- 報酬傾向タグ（装備寄り / 遺物寄り / 回路寄り / 通貨寄り など）
- 特記事項（例：宝箱多、罠多、エリート）


### 3.4 危険度（★）の意味（難易度スケーリング）
- 危険度（★1〜5）は「そのフロアの難しさ」を表す指標で、主に以下へ反映する
  - **敵出現量（Threat Budget / TB）** の増減
  - 「重い敵（硬い・範囲/支援など）」の混入率の増減
  - （任意）報酬の質の強化（高レア率アップ、★5は高レア候補保証 等）
- ★は分岐カードで提示し、ユーザーは「難しいが旨い」か「安全に進む」かを選べる

### 3.5 ★の出現分布（20階版：初期値）
- 序盤は★1〜3中心、終盤ほど★4〜5が混ざるようにする（学習曲線＋リスク/リターン）
- 推奨（分岐が発生する通常階のみ）
  - 1–3階：★1=50% / ★2=35% / ★3=15%
  - 6–8階：★1=15% / ★2=45% / ★3=30% / ★4=10%
  - 11–13階：★2=35% / ★3=35% / ★4=20% / ★5=10%
  - 16–18階：★2=15% / ★3=35% / ★4=30% / ★5=20%
※エリートは★3〜5のみ（16章）なので、上表は「戦闘/宝箱/罠」用の目安

### 3.6 フロアタイプ抽選の重み（20階版：初期値）
分岐候補は2択。各候補は以下の重みで抽選する（例）。
- 1–3階：戦闘55 / 宝箱25 / 罠20 / エリート0（序盤は出さない）
- 6–8階：戦闘45 / 宝箱25 / 罠20 / エリート10
- 11–13階：戦闘40 / 宝箱20 / 罠20 / エリート20
- 16–18階：戦闘35 / 宝箱15 / 罠20 / エリート30

## 4. フロアの基本構造（大広間）

### 4.1 進行単位
- **1フロア = ひとつの大広間**
  - 広間（敵/宝箱/罠） → 条件達成で階段出現 → 次階へ


### 4.1.1 フロア遷移（戻れない一方通行）
- 階段は「次フロアへ進むための出口」のみを持つ
- 次フロアへ移動した時点で **前フロアへ戻ることはできない**（戻り階段は生成しない）
- 次フロア開始時は、ゴーレムが **開始地点にスポーン** してフロアが開始される  
  - 表現：フロアに「ポン」と出現する（入口階段の演出/オブジェクトは不要）
- 生成制約として、開始地点の周囲には **安全圏** を確保する（スポーン安全圏（入口安全圏）は“スポーン安全圏”として扱う）


### 4.2 フロア内に存在し得る要素
- 敵（通常 / エリート / ボス）
- 宝箱
- 罠
- 階段（出口）

## 5. 情報の見え方（プレイヤー視点）

- プレイヤーからは **敵・宝箱・罠をすべて視認可能**（常時表示）
- **ミニマップは最初から全域表示**（探索で埋める方式は採用しない）

> 目的：AIが「見えている罠」に突っ込む等、挙動観察のハラハラを演出する。

---

## 6. 探索センサー（AI用情報）

- AIの判断入力として探索センサーを用意する
- **遮蔽は無視（壁越し検知）**
  - フロアは基本的に大広間で、壁で区切られた迷路構造を想定しない
  - 遮蔽物があっても、大きな柱・オブジェクト程度
- センサーは距離/範囲（R）を持てる（推奨：装備/遺物で拡張可能）
- センサー例（MVP）
  - 最寄り宝箱：距離/方向、宝箱種別（通常/トラップ）、（任意）TrapTier
  - 最寄り罠：距離/方向、危険状態（予兆中か等）
  - 最寄り敵：距離/方向
  - 出口（階段）：距離/方向

---

## 7. 階段（出口）出現ルール

- 通常フロア：**敵の全滅で階段が出現**
- ボスフロア：**ボス撃破で階段が出現**
  - ボス撃破と同時に残存雑魚は消滅（死亡扱い、ドロップなし推奨）

## 8. 宝箱

- 宝箱はフロア内に配置され、**いつでも操作できる**
- 宝箱は原則 **1回限り**
- 宝箱は以下の2種：
  - **通常宝箱**：開封で即報酬を獲得
  - **トラップ宝箱**：解除→開封。解除失敗または強制開封でトラップ発動

### 8.1 通常宝箱
- インタラクト（開封）で即座に報酬を獲得する

### 8.2 トラップ宝箱（解除あり）
- トラップ宝箱は **見た目/アイコンで区別**できる（常時視認可能）
- トラップ宝箱を開封しようとした場合の挙動
  - **デフォルト（確認UI）**：ユーザーが **解除 / 強制開封 / やめる** を選ぶ
  - **AI専用ACT**：AIが「解除開封」「強制開封」の専用ACTチップを実行した場合、**UIを出さず**そのまま処理する

#### 8.2.1 確認UI（デフォルト）
- 表示タイミング：トラップ宝箱に対して「宝箱開封（確認）」を実行したとき
- UI表示中：ゲーム進行とAI更新を **一時停止**（選択待ち）
- UI表示（最小）
  - 解除成功率（%）
  - 失敗時の効果タイプ（ダメージ/毒/ステータスダウンのいずれか）
  - トラップ宝箱の報酬ボーナス（**レア率+**：TrapTierに応じて変動）

#### 8.2.2 AI ACTチップ（宝箱関連）
- **宝箱開封（確認）**
  - 通常宝箱：即開封（報酬獲得）
  - トラップ宝箱：確認UIを出す（解除/強制開封/やめる）
- **宝箱解除開封**
  - トラップ宝箱：解除アクション（チャネル）→ 成功判定 → 開封
  - 通常宝箱：即開封
- **宝箱強制開封**
  - トラップ宝箱：解除せず開封（トラップ **100%** 発動）
  - 通常宝箱：即開封
- 実行前提（MVP）：インタラクト範囲内に宝箱があること（無い場合は Failure）

#### 8.2.3 解除アクション（初期値）
- チャネル時間：**1.2s**
- チャネル中に被弾しても解除は継続してよい（MVP簡略）。※必要なら中断仕様に変更可

#### 8.2.4 チップ結果の返し方（Success/Failure/Running）
- Running：チャネル中 / UI選択待ち
- Success：解除成功（トラップ無効化 → 開封 → 報酬獲得）
- Failure：
  - 解除失敗（トラップ発動 → 開封 → 報酬獲得）
  - 強制開封（トラップ発動 → 開封 → 報酬獲得）
  - 「やめる」を選択（宝箱は未開封）

#### 8.2.5 解除判定（初期値）
- トラップ宝箱は **TrapTier（1〜4）** を持つ（20階版の目安）
  - 1–5階：Tier1 / 6–10階：Tier2 / 11–15階：Tier3 / 16–20階：Tier4
- 基本成功率：Tier1=90% / Tier2=80% / Tier3=70% / Tier4=60%
- 修正（任意）：装備/遺物/工房解禁で成功率を増減してよい（上限95%を推奨）

### 8.3 トラップ効果（失敗/強制開封時）
- 効果は以下から **1つ** を抽選（同一宝箱で複数同時発生はしない）
  1) **ダメージ**：最大HP割合ダメージ（目安：Tier×5% + 5%）  
     - 例：Tier1=10%、Tier4=25%
  2) **ステータスダウン**：攻撃/防御/移動のいずれか低下（目安：-15%〜-30%）  
     - 持続：**フロア終了まで**（短ラン設計に合わせて明確に）
  3) **毒**：一定時間の継続ダメージ（目安：**10s**、1sごとに小ダメージ）
- 事故防止（推奨）
  - トラップで **即死しない**（最低HP1残し、またはダメージ上限を最大HPの30%に制限）

### 8.4 報酬（通常宝箱との価値差）
- 通常宝箱：通常の宝箱報酬（1枠）
- トラップ宝箱：**報酬レア率ボーナス**（解除成否に関わらず適用）

#### 8.4.1 レア率ボーナス（初期値）
- トラップ宝箱は TrapTier（8.2.5）に応じて、宝箱報酬のレアリティ抽選にボーナスを与える。
- 方式（MVP）：**コモン以外（アンコモン以上）の抽選重み**に `RARITY_WEIGHT_MULT` を掛ける（正規化して確率に変換）。
- `RARITY_WEIGHT_MULT`（初期値）
  - Tier1：×1.10（レア率+10%相当）
  - Tier2：×1.20（レア率+20%相当）
  - Tier3：×1.30（レア率+30%相当）
  - Tier4：×1.40（レア率+40%相当）

> 表示（UI）：例「レア率+20%」のように提示する（内部は重み乗算）。

> 意図：敵増援の代わりに「解除の成否」「開けるタイミング（戦闘前/後）」でリスク/リターンの意思決定を成立させる。

## 9. 罠

本作の罠は「**見えているのに踏む**（または踏ませる）」が面白さになるよう、
**視認性**と**回避可能性**を最優先に設計する。

### 9.1 共通ルール（MVP〜拡張共通）

- **罠は常時視認可能**（プレイヤー視点）
- **回避が成立する予兆（テレグラフ）**を必ず持つ
  - 静的罠（床の針など）は「**床見た目そのもの**」が予兆（踏まなければ安全）
  - 動的罠（噴炎/射線/爆発など）は「**赤床/赤線/点滅**」を出してから発動
- **HazardTilesへ統合**
  - 静的罠：常に該当タイルを `HazardTiles` に含める（＝踏みたくない床）
  - 動的罠：**予兆中＋発動中＋持続床**を `HazardTiles` に含める
- **基本は敵味方共通で当たる**（環境ダメージとして扱う）
  - MVPでは「罠無効の敵」は作らない（将来、耐性や無効を追加しても良い）
- **不可避禁止**（生成制約で担保）
  - 入口安全圏に置かない
  - 罠密度・重なりに上限（9.5）
- 事故防止（推奨）
  - 罠の単発ダメージに上限を設ける（9.4）
  - 同一トラップの1回の発動で、同一対象に多段ヒットしない（1回判定）

### 9.2 TrapTier（出現段階）

- TrapTierは **1〜4**。
- 基本はActと対応させる（宝箱のTrapTierと同じ考え方）。
  - 1–5階：Tier1
  - 6–10階：Tier2
  - 11–15階：Tier3
  - 16–20階：Tier4
- フロア生成時、罠は **`tier <= 現在Actの最大Tier`** の集合から抽選する（低Tier混在OK）。

### 9.3 罠セット（初期案）

まずは「**床爆発1種（MVP）**」で縦切りし、徐々に解禁していく。

| TrapID | 名称 | 解禁Tier | 形状 | 発動 | テレグラフ | 主効果 |
|---|---|---:|---|---|---|---|
| TR_BOMB_RUNE | 爆裂ルーン | 1 | 3×3 | 踏むと起動 | 起動後に赤床→爆発 | 範囲ダメ＋ノックバック |
| TR_SPIKE | 針床 | 1 | 1タイル | 接触 | 床見た目 | ダメ＋スロー |
| TR_FLAME_JET | 火炎噴射 | 2 | 直線（4〜6） | 周期 | 赤線→噴炎 | ダメ＋炎上 |
| TR_DART_LANE | ダーツ射線 | 2 | 直線（全長） | 踏板/周期 | 赤線→射出 | ダメ＋短スタン |
| TR_POISON_VENT | 毒ガス噴出口 | 3 | 3×3 | 周期 | 緑床→噴出 | 毒（DoT） |
| TR_LIGHTNING_PYLON | 雷撃柱 | 3 | 1タイル（周辺） | 近接反応 | 青床→落雷 | ダメ＋スタン |
| TR_LASER_EMITTER | レーザー照射 | 4 | 直線（全長） | 周期 | 赤線→照射 | 高ダメ（線） |

#### 9.3.1 爆裂ルーン（TR_BOMB_RUNE）
- **見た目**：床にルーン（常時視認）
- **発動**：ユニットが踏むと起動（以後クールダウンが終わるまで再起動しない）
- **テレグラフ**：起動後、中心＋周囲（3×3）に赤床点滅
- **発動**：爆発（3×3）
- **HazardTiles**
  - ルーン中心タイル：常時Hazard（踏まないため）
  - 起動中：3×3をHazard（予兆〜爆発判定まで）

#### 9.3.2 針床（TR_SPIKE）
- **見た目**：針/格子床（常時視認）
- **発動**：接触で即ヒット（クールダウンあり）
- **HazardTiles**：該当タイルは常時Hazard

#### 9.3.3 火炎噴射（TR_FLAME_JET）
- **見た目**：壁/床スリット（常時視認）
- **発動**：周期で噴射（例：2.8s周期）
- **テレグラフ**：直線に赤線（短い点滅）
- **HazardTiles**：予兆線＋噴射線（発動中）

#### 9.3.4 ダーツ射線（TR_DART_LANE）
- **見た目**：壁の射出口＋床の踏板（常時視認）
- **発動**：踏板にユニットが乗ると起動（or 周期でも可）
- **テレグラフ**：射線（直線）に赤線
- **HazardTiles**：予兆線＋射線（発動中）

#### 9.3.5 毒ガス噴出口（TR_POISON_VENT）
- **見た目**：床グリル（常時視認）
- **発動**：周期で噴出（例：3.2s周期）
- **テレグラフ**：3×3に緑床
- **HazardTiles**：予兆床＋ガス床（持続中）

#### 9.3.6 雷撃柱（TR_LIGHTNING_PYLON）
- **見た目**：コイル柱/導電床（常時視認）
- **発動**：周囲にユニットが入るとチャージ（例：半径2）→落雷
- **テレグラフ**：中心タイルに青床点滅（周囲に小放電）
- **HazardTiles**：予兆床＋落雷判定床

#### 9.3.7 レーザー照射（TR_LASER_EMITTER）
- **見た目**：壁のエミッタ（常時視認）
- **発動**：周期で照射（例：4.0s周期）
- **テレグラフ**：照射予定の直線に赤線
- **HazardTiles**：予兆線＋照射線（発動中）

### 9.4 パラメータ（初期値）

#### 9.4.1 テレグラフ時間
- `TELEGRAPH_TIME_BY_TIER`
  - Tier1：1.0s
  - Tier2：0.9s
  - Tier3：0.8s
  - Tier4：0.7s

> AI Tick=0.1s 前提で、最大7〜10Tickの反応猶予を確保する。

#### 9.4.2 ダメージスケール
- 深層ほど罠ダメージが増える（14.1.1 と整合）
  - `TRAP_MULT(d) = 3 ^ ((d-1)/19)`（20階で×3）
- 罠ダメージ（割合系）の計算（推奨）
  - `dmg = MaxHP * base_percent * TRAP_MULT(depth)`
  - `dmg = clamp(dmg, 1, MaxHP * TRAP_DAMAGE_CAP)`
- `TRAP_DAMAGE_CAP = 0.35`（単発35%上限の目安）

#### 9.4.3 罠ごとの基礎値（base_percent 目安）
- **爆裂ルーン**：Tier1=0.08 / Tier2=0.10 / Tier3=0.12 / Tier4=0.14
- **針床**：Tier1=0.06 / Tier2=0.07 / Tier3=0.08 / Tier4=0.09
- **火炎噴射**：Tier2=0.06 / Tier3=0.07 / Tier4=0.08
- **ダーツ射線**：Tier2=0.08 / Tier3=0.09 / Tier4=0.10
- **雷撃柱**：Tier3=0.10 / Tier4=0.12
- **レーザー照射**：Tier4=0.10

#### 9.4.4 付与状態異常（目安）
- **スロー（針床）**：移動 -30%（Tier1=1.5s → Tier4=2.5s）
- **炎上（火炎噴射）**：2%/s ×3s（Tier3〜）、Tier4は2.5%/s
- **毒（毒ガス）**：2%/s ×6s（Tier3）、Tier4は2.5%/s
- **スタン（ダーツ/雷撃）**：
  - ダーツ：0.25s（Tier2）/ 0.30s（Tier3）/ 0.35s（Tier4）
  - 雷撃：0.35s（Tier3）/ 0.45s（Tier4）

> 状態異常は「重ね掛け上書き（残り時間を長い方に）」で良い（MVP簡略）。

### 9.5 生成・配置制約（不可避罠禁止）

#### 9.5.1 入口安全圏
- 開始地点から **半径3タイル**（目安）を入口安全圏とし、罠を配置しない。

#### 9.5.2 密度・重なり上限（★対応：確定）

生成の安定化と「不可避罠」の防止のため、密度は **2種類** で管理する。

- **HazardFootprintTiles**：その罠が「予兆/発動/持続」で `HazardTiles` になり得るタイル集合（生成時に概算）。
  - 例：爆裂ルーン=3×3、毒ガス=3×3、直線罠=直線長、雷撃柱=半径2 など
- **StaticHazardTiles**：常時Hazard（針床、爆裂ルーン中心 等）

生成時は以下の上限（歩行可能タイル比）を守る。

**A) HazardFootprint（罠の“危険カバー率”）上限**

| フロア種別 | ★1 | ★2 | ★3 | ★4 | ★5 |
|---|---:|---:|---:|---:|---:|
| 戦闘（通常） | 8% | 10% | 12% | 14% | 16% |
| 宝箱 | 12% | 14% | 16% | 18% | 20% |
| 罠 | 22% | 26% | 30% | 33% | 35% |
| エリート（★3〜5のみ） | - | - | 10% | 12% | 14% |

**B) StaticHazard（常時危険床）上限**

| フロア種別 | ★1 | ★2 | ★3 | ★4 | ★5 |
|---|---:|---:|---:|---:|---:|
| 戦闘（通常） | 2% | 3% | 4% | 5% | 6% |
| 宝箱 | 3% | 4% | 5% | 6% | 7% |
| 罠 | 6% | 7% | 8% | 10% | 12% |
| エリート（★3〜5のみ） | - | - | 3% | 4% | 5% |

**C) 罠個数（最低数の目安）**

> 「密度上限」はマップ形状・距離制約で置けない場合があるため、体験のブレ防止として下限も持つ。

| フロア種別 | ★1 | ★2 | ★3 | ★4 | ★5 |
|---|---:|---:|---:|---:|---:|
| 戦闘（通常） | 0 | 0 | 1 | 1 | 1 |
| 宝箱 | 1 | 1 | 1 | 2 | 2 |
| 罠 | 3 | 4 | 5 | 6 | 7 |
| エリート（★3〜5のみ） | - | - | 0 | 0 | 1 |

**D) 生成での予算化（実装指針）**
- `footprint_budget = floor(WALKABLE_TILES * HazardFootprintCap)`
- `static_budget    = floor(WALKABLE_TILES * StaticHazardCap)`
- 各罠には `footprint_tiles`（概算）と `static_tiles`（常時Hazard分）を持たせ、配置時に予算を超えないようにする
  - MVP（爆裂ルーンのみ）の場合：`footprint_tiles=9`（3×3）、`static_tiles=1`

- 罠オブジェクト間の距離：中心同士 **2タイル以上**（目安）
- 同一タイルに複数罠の「発動判定」が重ならないようにする（特に線×線の交差は禁止推奨）


**E) 罠ごとの概算タイル数（`footprint_tiles / static_tiles`：確定）**

> ここでのタイル数は「密度予算（9.5.2）」のための**概算**。実際の `HazardTiles` はテレグラフ/発動タイミングで変動する。  
> `footprint_tiles` は **“その罠が危険になり得るタイルの和集合”**（静的Hazardも含む）として数える。

| TrapID | 名称 | footprint_tiles（概算） | static_tiles | 算出ルール（生成時） |
|---|---|---:|---:|---|
| TR_BOMB_RUNE | 爆裂ルーン | 9 | 1 | 3×3（中心1タイルは常時Hazard） |
| TR_SPIKE | 針床 | 1 | 1 | 1タイル（常時Hazard） |
| TR_FLAME_JET | 火炎噴射 | L | 0 | 直線長 `L = min(randint(4,6), ray_len)` |
| TR_DART_LANE | ダーツ射線 | L+1 | 1 | 射線直線長 `L = clamp(ray_len, 6, 12)` ＋踏板1タイル（常時Hazard） |
| TR_POISON_VENT | 毒ガス噴出口 | 9 | 0 | 3×3（予兆＋ガス持続の範囲） |
| TR_LIGHTNING_PYLON | 雷撃柱 | 13 | 1 | 半径2円（`dx^2+dy^2<=4`）＋中心1タイル（常時Hazard） |
| TR_LASER_EMITTER | レーザー照射 | L | 0 | 直線長 `L = clamp(ray_len, 8, 16)`（短すぎる場合は生成しない） |

- `ray_len`：発生源（壁スリット/エミッタ等）から向き方向に、**壁または障害物に当たるまでの歩行可能タイル数**。  
- `clamp(x, a, b)`：`a<=x<=b` に収める。
- 実装は「罠の置ける位置」を先に決めてから `ray_len` を計測し、上の式で `L` を確定させる（確定した `L` をそのまま予算消費に使う）。


#### 9.5.3 POI周りの安全
- 宝箱の周囲1タイル（8近傍）には、静的Hazardを置かない（強制被弾を防ぐ）。

### 9.6 MVP（縦切り）

- 最初の実装は **TR_BOMB_RUNE（床爆発）1種**。
- 段階的に TrapTier と罠種を追加する（9.3の解禁Tierに従う）。

## 10. ボス前フロア（インターミッション：回復＋ショップ）

### 10.1 回復（入場時即時）
- 入場時に **即時回復**（割合回復、AIの判断・移動は不要）
- 回復率：
  - `HEAL_RATE = BASE + RUN_BONUS + PERMANENT_BONUS`
  - `HEAL_RATE` は上限（cap）を持つ

#### 永続強化（PERMANENT_BONUS）
- 工房で **金塊（永続通貨）** を支払って解禁/強化する
- 強化は **+3%刻み**（例）で上がる
- **コスト逓増**：購入回数に応じて必要金塊が増える
- **上限**：最大強化値（%）または最大回数を設定する

> 目的：周回による安定化はするが、無限に強くなりすぎないようにする。

### 10.2 ショップ（UI遷移）
- 回復適用後にショップ画面へ遷移
- ショップ中はゲーム進行とAI更新を停止
- ユーザーが「終了」を選ぶと次の階へ進行（通常はボスフロア）

### 11.2 形式（MVP推奨）
- 提示：3候補
- 取得：1つ選択

## 12. 戦利品・通貨・清算

### 12.1 通貨の役割
- **古銭（ラン通貨）**
  - 入手：敵/宝箱/報酬等（詳細は別途テーブル化）
  - 使用：ショップ購入、リロール等（ラン中のみ）
  - 敗北時：ロスト
- **金塊（永続通貨）**
  - 使用：工房で研究/解禁/永続アップグレード（例：インターミッション回復率+3%）
  - 入手：ラン終了時の清算（古銭換金や深層ボーナスなど）

### 12.2 清算（帰還/クリア時）
- ラン終了時（帰還またはボス撃破）に清算を行い、工房へ戻る
- 清算例：
  - 未使用の古銭を **金塊へ換金**（`COIN_TO_BAR_RATE`）
  - 到達階層に応じた **深層ボーナス** を金塊に付与（深層ほど増える）
    - 例：`DEPTH_BONUS_TABLE` / `BAR_MULT_BY_DEPTH` などで定義

> 目的：浅い階の反復より、深く潜るほど金塊が増えて得になる設計にする。

---


### 12.3 持ち帰り資源（素材/設計図）
- **素材** と **設計図** は「持ち帰り資源」。ラン中に獲得し、**帰還/クリア時に工房へ確定**する（敗北時はロスト）。
- ラン内ビルド（装備/遺物/消耗品/回路強化）は **持ち帰れない**（＝自動変換もしない）。

### 12.4 初期テーブル（目安）
> バランスは後で調整する前提。まずは「深く潜るほど得」「ボス撃破が一番得」を担保する。

#### 12.4.1 金塊（永続通貨）
- 清算時に以下を合算して付与する。
  - `bars += floor(coin_unused / COIN_TO_BAR_RATE)`
  - `bars += DEPTH_BAR_SUM(depth_cleared)`（フロア到達ボーナス）
  - `bars += BOSS_BAR_BONUS_SUM(bosses_defeated)`（ボス撃破ボーナス）
- `COIN_TO_BAR_RATE = 200`（未使用古銭200=金塊1 の目安）
- フロア到達ボーナス（クリアした最深階までを合算）
  - Act1（1–5F）：+1 /F
  - Act2（6–10F）：+2 /F
  - Act3（11–15F）：+3 /F
  - Act4（16–20F）：+4 /F
- ボス撃破ボーナス
  - 5F：+5、10F：+8、15F：+12、20F：+20

#### 12.4.2 素材（永続資源）
- 素材はラン中に獲得して保持し、帰還/クリアで確定する（敗北時ロスト）。
- 入手量（目安）
  - 通常フロア（戦闘/罠）：`20% + (★-1)*5%` の確率で **素材×1**
  - 宝箱フロア：宝箱1つにつき **35%で素材×1**（トラップ宝箱は **素材×1確定 + 35%で追加×1**）
  - エリートフロア：クリアで **素材×2**（★5は素材×3）
  - ボス撃破：5F=素材×3 / 10F=×4 / 15F=×5 / 20F=×7

#### 12.4.3 設計図（永続解禁）
- 設計図はラン中に獲得して保持し、帰還/クリアで確定する（敗北時ロスト）。
- 入手（目安）
  - 5/10/15Fボス：**設計図×1 確定**（TierはActに対応）
  - 20Fラスボス：**設計図×1 確定**（上位Tier）
  - エリートフロア：★3=5% / ★4=10% / ★5=20% で設計図×1
  - トラップ宝箱：Tier4のみ 5% で設計図×1（それ以外は無し）

#### 12.4.4 1ラン期待値（目安）
- 20Fクリア：金塊 **約90〜110**（未使用古銭次第）、素材 **25〜40**、設計図 **4（+エリート運）**

## 13. 失敗・撤退・時間圧の設計

### 13.1 時間圧（制限時間）
- **採用しない**（崩壊ゲージ等のタイムリミット要素は導入しない）

### 13.2 失敗（敗北）
- 敗北条件：**HPが0になった時点でラン終了**
- 敗北時の扱い：**ラン中に取得したアイテム／戦利品は全てロスト**（未帰還のため持ち帰れない）
  - 装備・遺物・消耗品・回路関連・古銭・素材・金塊相当・設計図 など、ラン中に得たもの全て

### 13.3 撤退（帰還：安全ポイント撤退）
- 実行タイミング（安全ポイントのみ）：
  - **フロアクリア後の「次フロア分岐選択UI」上で「帰還」を選べる**
    - 分岐がある階：次フロア候補（2択など）と並べて「帰還」ボタンを表示
    - 次フロアが固定の階（インターミッション／ボス等）：同じUI枠で「次へ進む」＋「帰還」を表示
- 撤退時の扱い：
  - ランを終了し、**清算（12章）を行って工房へ戻る**
  - 以後のフロア報酬やボス報酬は得られない（早期終了の機会費用）

### 13.4 中断（現実都合の終了）※撤退と別枠
- 現実都合のための「中断」を用意する（推奨）
- 中断は「撤退」と違い、ランを終わらせず **再開可能** とする
- 実装最小：フロア開始時点でのオートセーブ等で再開

## 16. エリートフロア詳細（初期値）

### 16.1 出現ルール（分岐カード）

### 16.2 エリート敵の生成・強化（参照）
- エリート本体＋取り巻きの編成、取り巻きTB、★によるエリート強化係数などは **「敵キャラ仕様_v2.md」** を参照

### 16.3 罠・宝箱（少〜標準）
- 罠：少〜標準（★3:0〜1 / ★4:0〜2 / ★5:1〜2）
- 宝箱：0〜1（出すならエリートから離れた位置に1つ）

### 16.4 クリア報酬（強化）
- エリートクリア報酬：**4候補 → 1つ選択**  
- （任意）★で質を強化：★5は高レア候補が最低1つ保証、等

## 17. ボスフロア詳細（初期値）

### 17.1 ボス周期と終点
- `BOSS_INTERVAL=5` を想定  
- ボス階：5/10/15/20（20階がラスボス）

### 17.2 ボスフロアの基本生成
- ボスは開始地点から離れた位置に1体スポーン（入口安全圏内に危険床/敵を置かない）
- ボス戦では「予兆（テレグラフ）→回避」が成立することを最優先する（不可避を作らない）

### 17.3 クリア条件と雑魚の扱い
- **ボス撃破で階段出現**
- ボス撃破と同時に残存雑魚（取り巻き等）は消滅（死亡扱い、ドロップなし推奨）

### 17.4 ボス報酬
- 5〜15階ボス：**4候補 → 1つ選択**（通常より強い報酬）
- 20階ラスボス：撃破でランをクリア扱いとして終了し、清算へ  
  - （任意）クリア感のある報酬：設計図確定、等

### 17.5 ボスの攻撃パターン（参照）
- ボス共通の不可避防止ルール、各ボスの技構成（5F/10F/15F/20F）などの詳細は **「敵キャラ仕様_v2.md」** を参照

## 18. クリア後のループ（新ダンジョン解放）

### 18.1 基本方針
- 現行ダンジョンは **20階（ラスボス）クリアで区切り**とする（20階撃破でランは「クリア扱い」で終了し清算へ）。
- 20階クリア後は、工房（ハブ）で **次の新ダンジョンを解放**し、以後は「出撃前にダンジョン選択」を行う。

> 目的：1ランの尺を現実的に保ちつつ、長期の目標を「新ダンジョン解放」として提供する。

### 18.2 ダンジョン選択（出撃前UI）
- 工房（ハブ）に「ダンジョン選択UI」を置く（出撃時に選択）。
- 表示項目（例）：
  - ダンジョン名 / 推奨難易度（★など）
  - 主要報酬（設計図テーブルの方向性、素材カテゴリ等）
  - クリア状況（未踏破 / 20階クリア済み）
  - NEW / LOCK 表示（解放演出）

### 18.3 新ダンジョンの“差分レイヤー”
- 各ダンジョンは、以下の差分を持つ（コアは共通）：
  - 見た目テーマ（背景/床/壁/SE/BGM）
  - 敵セット（同じ役割5種でも“亜種”として性能/耐性/攻撃パターンを差し替え）
  - 罠セット（予兆付きの危険床/射線を追加し、不可避は禁止）
  - 報酬プール（遺物/装備/チップ/設計図のテーブル差分）
  - ボスセット（5/10/15/20階のボスを差し替え、20階は各ダンジョンのラスボス）

### 18.4 解放条件（最小）
- **前ダンジョンの20階ラスボス撃破（クリア）で、次ダンジョンを解放**する。
- （任意）解放演出後に「工房で解放ボタン（無料 or 金塊消費）」を押す方式にしてもよい。

### 18.5 旧ダンジョンの価値（周回動機）
- 旧ダンジョンも出撃可能とし、周回価値を残す：
  - ダンジョンごとに設計図・素材テーブルを差別化する（欲しい解禁物によって潜り先が変わる）。
  - 金塊/素材の期待値は新ダンジョンが上になりやすいが、旧ダンジョンは“安定周回”として残る。

### 18.6 将来拡張（メモ）
- ダンジョン数が増えた後の拡張案：
  - クリア後：周回難易度（Ascension）や日替わりシード等
  - 「第2ダンジョン到達で新チップ系列が解禁」など、AI回路側の拡張導線
